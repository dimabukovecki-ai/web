# Chess Online — глобальна онлайн-гра

Готовий вебпроєкт із шаховою дошкою, кімнатами за кодом і ходами в реальному часі.

## Запуск на комп'ютері

1. Встанови **Node.js 18 або новіший** з https://nodejs.org/
2. Розпакуй ZIP у папку.
3. Відкрий цю папку у VS Code.
4. У VS Code відкрий **Terminal → New Terminal**.
5. Виконай команди:

   ```bash
   npm install
   npm start
   ```

6. Відкрий у браузері `http://localhost:3000`.

## Як грати з другом

1. Створи кімнату.
2. Скопіюй код кімнати й надішли другу.
3. Друг відкриває сайт на своєму пристрої та вводить код у полі.
4. Коли обидва гравці в кімнаті, можна ходити.

## Як зробити сайт доступним усім через інтернет

Цей проєкт потребує **Node.js-хостингу**, який підтримує постійний процес Node.js і WebSocket/Socket.IO. Завантаж файли проєкту в репозиторій GitHub, а потім створи на Node.js-хостингу Web Service із командою запуску `npm start`. Якщо хостинг дає змінну `PORT`, сервер використає її автоматично.

Звичайний статичний хостинг на кшталт GitHub Pages сам по собі не запустить сервер Socket.IO. Якщо NomadHost у твоєму тарифі не підтримує Node.js, цей проєкт там не запрацює як онлайн-мультиплеєр.

## Важливо

- Кімнати зберігаються в пам'яті сервера; після перезапуску сервера активні партії зникнуть.
- Ходи перевіряються сервером через `chess.js`.
- Скрипт шахових правил у браузері завантажується з CDN, тож для першого завантаження потрібен інтернет.
